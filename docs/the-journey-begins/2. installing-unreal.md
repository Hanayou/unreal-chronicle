---

Before we can build worlds, we need the tools. This chapter covers everything you need to **get the Unreal Engine installed and ready**—without yet creating a project. That comes next.

---

### 📦 The Epic Games Launcher

Unreal Engine is distributed through the **Epic Games Launcher**—a single app where you can:
- Download and manage different versions of UE
- Access sample projects and free content
- Browse the Marketplace for assets
- Launch installed projects

Think of it as your **portal into the Unreal ecosystem**.

---

### 📥 Step 1 — Download & Install the Epic Games Launcher

1. Go to the official Unreal Engine site: [https://www.unrealengine.com](https://www.unrealengine.com)
2. Click **Download** and choose your platform (Windows or Mac).  
   _(Linux users: UE5 is available via source on GitHub, but we’ll focus on Epic’s packaged installer for now.)_
3. Run the installer and follow the prompts.
4. Sign in or create a free Epic Games account.

💡 **Tip:** The Epic Games Launcher is also where Fortnite lives—don’t be surprised if you see it featured front-and-center. You don’t need Fortnite to use Unreal.

---

### 🛠 Step 2 — Navigating to Unreal Engine

Once installed:
1. Open the Epic Games Launcher.
2. In the left-hand menu, click **Unreal Engine**.
3. You’ll see several tabs—**Home**, **Learn**, **Marketplace**, **Library**.

For now, we’ll focus on the **Library** tab—this is where your installed engine versions will appear.

---

### 📥 Step 3 — Installing Unreal Engine 5

1. In the **Library** tab, click the **+ Install Engine** button.
2. Choose the version of Unreal Engine 5 you want to install.  
   - **Recommendation:** Unless you have a specific reason (e.g., working with an older project), install the **latest stable release**.
3. Select the installation location.
   - **Tip:** Unreal Engine can be large (~20–50 GB depending on content), so choose a drive with plenty of free space.
4. (Optional) Check **Starter Content**. This adds a small library of basic materials, meshes, and textures—useful for quick prototyping.
5. Click **Install**.

---

### ⚙️ Step 4 — Setting Your Default Project Location

Even though we’re not creating a project yet, it’s worth knowing where UE will save them by default:
- By default, projects are stored in `Documents/Unreal Projects` (Windows) or `~/Documents/Unreal Projects` (Mac).
- You can change this in the Project Browser later, or by setting your preferred folders in the engine.

💡 **Tip:** If you plan to work on large projects, consider using a fast SSD for both engine and project files.

---

### 🔍 Additional Notes

- **Multiple Versions**: You can have more than one UE version installed. This is useful when working on older projects that require a specific version.
- **Preview / Beta Versions**: Occasionally, Epic releases preview builds for upcoming features. These can be fun to explore but may be unstable—avoid them for production work.
- **Updates**: The launcher will notify you when a new version is available. You can update in place or install it alongside the existing one.
